# Public deployment without login

The `docs` folder is a static Employee Support Hub designed for GitHub Pages. It does not use ChatGPT authentication.

1. Push this repository to GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/docs` folder, then save.
5. GitHub will provide a public URL such as `https://USERNAME.github.io/REPOSITORY/`.

After deployment, regenerate the permanent QR code using the exact GitHub Pages URL. Do not keep using the QR code that points to the ChatGPT-hosted address.
