# Adecco Employee Resource Hub

A responsive internal resource directory for employee payroll, benefits, attendance, safety, transportation, work resources, and leadership contacts.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Quality checks

```bash
npm test
npm run lint
```

## Production build

```bash
npm run build
npm run start
```

The React application in `app/` powers the hosted Site. The synchronized static version in `docs/` powers GitHub Pages.
